# Real Uniform Generator

Blender 5.2向けの制服プリーツスカート生成アドオンです。

## 現在の機能

- サイドバーから制服プリーツスカートを生成
- プリーツ数、丈、ウエスト、裾幅、生地厚を調整
- ウエストベルト、裾、ステッチ、ファスナーを生成
- 濃紺ウール混風のプロシージャルマテリアル
- GLB / FBX / OBJへの書き出し

## インストール

1. このリポジトリをZIPでダウンロードします。
2. Blenderで `Edit > Preferences > Add-ons > Install from Disk` を開きます。
3. ZIP内の `real_uniform_generator` フォルダをZIP化したものを選択します。
4. `3D View > Sidebar > Uniform` を開きます。

## 開発状況

第1版では、実際にインストールして生成・書き出しできるアドオン基盤を実装しています。今後、クロスシミュレーション、UV、布プリセット、より精密なプリーツ構造を追加します。
