# Realism Specification

## 目的

日本の冬制服用・濃紺・ナイフプリーツ・左脇コンシールファスナー・裏地付きの一着を、実物の構造に沿って再現します。

## 形状の品質基準

- 布は一枚の連続した経路であること
- 表プリーツ、折り山、奥プリーツ、折り返しを別々の板として作らないこと
- ウエストではプリーツを縫い止め、移行区間を経て下部で開くこと
- 外側へ独立した裾リング、パイプ、トーラスを置かないこと
- 裾見返しは各折りへ追従し、内側だけに存在すること
- ベルトは中空で、表、上折り、内側、取付側を持つこと
- ファスナー部品は外側から原則見えないこと
- ファスナー開きとメッシュ端、縫い代、テープ、コイルの位置が一致すること

## マテリアルの品質基準

- Base Colorに撮影時の照明・影を残さない
- Roughnessは単一値にせず、微小な糸・染色差だけを含める
- NormalはOpenGLを基準とし、DirectX入力は自動変換する
- Heightは数十〜数百µm級の織り目に限定し、巨大な凹凸を作らない
- UVは画像の物理サイズと一致させる
- Metallicは0
- Clearcoatは原則0
- Sheenは弱く、布の縁・斜入射でのみ感じる強さ
- 近接用では実物生地の4K〜8K PBRを使用

## スケール分担

| スケール | 表現方法 |
|---|---|
| シルエット、山谷、ベルト、裾、開き | 実メッシュ |
| 布の落ち、微小なしわ | Cloth / Shape Key / Displacement |
| 織り目 | Normal + Height |
| 糸の色・粗さ差 | Base Color + Roughness |
| 毛羽 | Sheen、必要時のみHair Curves |
