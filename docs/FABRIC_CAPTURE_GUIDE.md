# 実物生地の撮影ガイド

## 最低限必要なもの

- 生地見本、またはスカートの平らな部分
- カメラを固定する三脚
- 定規
- グレーカードまたはカラーチェッカー
- 大きな拡散光
- 可能なら偏光フィルター

## Base Color撮影

1. 生地を張りすぎず、平らに置きます。
2. カメラのセンサー面を生地と平行にします。
3. 定規を同一平面へ置きます。
4. 左右から同程度の拡散光を当てます。
5. ISO・絞り・シャッター・WBを固定します。
6. RAWで撮影します。
7. 影、ハイライト、周辺減光を補正してからSamplerへ入れます。

## Photometric Stereo用

カメラと生地を完全に固定し、照明だけを移動して撮ります。

- 上
- 下
- 左
- 右
- 左上
- 右上
- 左下
- 右下

各画像は同じ露出・WBで撮ります。これにより、単純な明度変換より正確なNormal/Height推定が可能になります。

## 撮影範囲

- 全体の色・むら確認: 20〜30cm四方
- 織り目取得: 5〜10cm四方
- 糸・毛羽確認: マクロ接写

アドオン標準の `テクスチャ実寸` は10cmです。撮影・SamplerのPhysical Sizeも同じ値へ合わせると、Blender上で糸目の大きさが崩れません。
